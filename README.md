# CodeAlpha Hangman Project

A text-based Hangman game built in Python for CodeAlpha internship Task 1.

## How it works
- Player guesses letters one at a time to reveal a hidden word
- 6 incorrect guesses allowed before the game ends
- Displays guessed letters so far after each turn
- Shows a simple emoji-based hangman progression as attempts run out
- Option to play again after each round

## Concepts used
random, while loops, if-else, strings, lists
